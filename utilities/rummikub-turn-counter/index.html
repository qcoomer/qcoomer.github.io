Turn Counter

Set a turn length, choose up to four players, pick exactly where each player is sitting, define turn order, then tap the fullscreen timer to pass the turn and restart the countdown.

Turn setup

Mobile and iPad friendly. Seat selection can be done directly from the table position buttons.

Players

Each active player needs one unique seat and one unique turn position.

Table preview

Turn order appears on each active player.
Seat selection: Use the top, left, right, and bottom buttons inside each player card.
Turn flow: The timer can be tapped early or after time runs out to pass to the next player.
Sounds: A ding plays at 10 seconds remaining, and a buzzer plays once when time reaches 0.
